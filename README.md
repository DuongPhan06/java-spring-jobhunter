# java-spring-jobhunter
A modern full-stack job recruitment platform built with Spring Boot, React, and TypeScript, featuring job management, user authentication, and role-based authorization.

## Technologies
- Java 17
- Spring Boot
- MySQL

## How to Run
1. **Clone the repository**
   git clone https://github.com/DuongPhan06/java-spring-jobhunter.git
   cd java-spring-jobhunter

2. **Configure MySQL**
   - Create a database named jobhunter.
   - Update the database username and password in (application.properties)

3. **Run the application**
   ./gradlew bootRun

4. **Access the backend**
   - Server: `http://localhost:8080`
   - Use Postman to test REST APIs.
